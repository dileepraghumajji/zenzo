## 🚀 Current Project

### [Zenzo](https://github.com/dileepraghumajji/zenzo) — Membership Management SaaS

> Multi-tenant SaaS for recurring-attendance businesses (gyms, martial arts academies, yoga studios).

```
📦 Turborepo monorepo
├── apps/web          → Next.js 14 App Router
├── packages/database → Supabase client + RLS
├── packages/ui       → Shared component library
└── packages/utils    → Formatters, slugify, helpers

Features in build:
  ✅ Multi-tenant workspaces  ✅ Role-based access (owner/staff/member)
  🔨 Member management        🔨 Attendance tracking
  🔨 Fee plans & payments     🔨 WhatsApp notifications (Interakt)
```

**Stack:** `Next.js 14` · `Supabase` · `Razorpay` · `Interakt` · `Turborepo` · `Vercel`
